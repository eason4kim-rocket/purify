# Purify Search — Motion Rhythm V1 (Paused Archive)

> 状态：动效阶段已暂停。Visual Lock V1 期间页面强制静态；下方旧节奏仅作为历史参考，不是当前生产规范。原“点阵变成人形”方向已废弃，后续动效必须从已锁定的抽象方块构图重新设计。

> V1.1 例外：Hero 方块场已恢复实时预览，用于校准密度、色阶与运动。当前实现采用
> 14 秒环境循环、桌面 96–118 列 × 34 行候选网格、更高比例的深蓝锚点，以及约 46%
> 的主动漂移方块；系统 reduced-motion 与截图模式仍返回静态排列帧。下方第 4 节的
> 16 秒旧参数保留为历史参考，不再代表当前实现。

## 1. 动效母题

动效只表达五件事：**出现、观察、连接、变化、落定**。

页面不是一条持续兴奋的演示片。它应有明显呼吸：首屏建立世界观，影片把世界带进来，点阵把信息还给人，产品段证明方法，最后回到安静、开阔的未来。

硬约束：

- 正常文档流，不劫持滚动，不把滚轮映射成视频时间轴。
- 同一视口只允许一个主要运动源。
- 标题与关键信息始终存在于 DOM；快速滚过也不会丢失内容。
- 不使用跟随光球、HUD、代码雨、霓虹成功态、全屏粒子常驻、夸张 3D 翻转。
- 方块只属于 Hero、Living Evidence 抽象图，以及第三幕到产品段的一次短暂呼应。
- 影片默认静音自动播放；有声版本必须由用户主动开启。

## 2. 整页强弱曲线

四幕之外保留一个产品证明间奏，但不把它命名为“第五幕”。

| 页面区间 | 全页参考进度 | 建议滚动长度 | 动态强度 | 唯一视觉赢家 | 节奏作用 |
|---|---:|---:|---:|---|---|
| 第一幕 Hero | 0–13% | 110svh | 32% | 蓝色方块矩阵与命题 | 建立语气，慢慢吸引注意 |
| Hero → 影片 | 10–14% 桥接窗 | 25–35vh | 12% | 白色留白 | 第一次呼吸，不做形态变换 |
| 第二幕 World in Motion | 13–30% | 170svh | 68% | 28.8 秒真实影片 | 全站第一次高峰 |
| 影片 → 共同记忆 | 27–32% 桥接窗 | 30–40vh | 8% | 曝光到白 | 清场，让影片余韵落下 |
| 第三幕 Living Memory | 30–54% | 180svh | 48% | 点阵到人的观察 | 从数据回到人 |
| Living Evidence 间奏 | 54–82% | 210svh | 58% | 单槽三态与证据记录 | 技术证明，不做功能墙 |
| 产品 → 未来 | 79–84% 桥接窗 | 30–40vh | 18% | 开放的白色空间 | 收束技术语言 |
| 第四幕 Future | 82–95% | 135svh | 14% | 最终宣言 | 全站最长的安静落点 |
| Footer | 95–100% | 自然高度 | 0% | 链接与版权信息 | 完全静止 |

全页约 8 个视口。以上全页百分比只用于 1440px 节奏 QA；正式实现以“章节边界从 viewport 90% 移动到 40%”映射局部 bridge progress，避免中英文和响应式高度变化破坏节奏。手机桥接区压缩为边界从 86% 到 56%，不做 sticky。高强度只出现在影片和产品自愈的短段落，二者不会同时运行。

## 3. Motion tokens

| 类型 | 时长 | Easing | 用途 |
|---|---:|---|---|
| Hover | 160–180ms | `cubic-bezier(.16,1,.3,1)` | 链接、按钮、标签 |
| 状态切换 | 220–320ms | `cubic-bezier(.16,1,.3,1)` | Tab、状态文本、轻位移 |
| 图片交接 | 400–650ms | `cubic-bezier(.37,0,.63,1)` | Living Evidence 三图切换 |
| 文案进入 | 700–900ms | `cubic-bezier(.16,1,.3,1)` | 标题、Lead、CTA |
| 媒体进入 | 900–1200ms | `cubic-bezier(.16,1,.3,1)` | 影片、纪实图片 |
| 章节清场 | 900–1200ms | `cubic-bezier(.7,0,.84,0)` | 退出、曝光到白 |
| Hero 环境循环 | 16s | 分段 easing | 方块呼吸与短暂排列 |

进入用较快的前半段，退出更克制；全站不用弹簧和回弹。

## 4. 第一幕：Hero 方块矩阵

### 首次加载 0–920ms

| 时间 | 事件 |
|---:|---|
| 0–300ms | 保持白底；真实 DOM 标题已经占位，避免布局位移 |
| 0–420ms | 导航由 `y:-10px / opacity:0` 落定 |
| 80–840ms | 方块矩阵按 12 个空间带进入，每带错开约 22ms，不从屏外飞入 |
| 180–500ms | Eyebrow 进入 |
| 240–900ms | H1 由 `translateY(18px)` 落定 |
| 420–820ms | Lead 进入 |
| 540–920ms | 主 CTA 与文本入口出现 |

首屏 920ms 后进入环境循环；在这之前不响应指针扰动。

### 16 秒环境循环

| 时间 | 状态 | 运动 |
|---:|---|---|
| 0–2.4s | Quiet observation | 只有 8–12% 方块移动 1–2px |
| 2.4–6.4s | Signal rising | 约 18% 方块沿 3–4 条不可见流场移动 2–6px |
| 6.4–8.6s | Brief alignment | 36–48 个方块旋转归零，排成一条不完整的宽路径 |
| 8.6–9.6s | Hold | 保持约 1 秒，让用户真正看见秩序 |
| 9.6–13.2s | Release | 路径松开但不原路倒放，沿闭合曲线继续 2–5px |
| 13.2–16s | Seam conceal | 回到起点；位置、旋转、opacity 与 0 秒完全一致 |

桌面环境位移不超过 6px、旋转不超过 1.5°、透明度波动不超过 0.12。指针只影响最近 8–12 个方块，位移上限 4px；移动端、触屏与低性能模式关闭。用户开始滚动后，循环权重在 Hero 本地进度 5–22% 内从 1 降到 0，再由离场转场接管。Hero 离开视口 15% 后立即暂停。

### 滚动离场

- Hero 本地进度 0–45%：环境循环独立运行。
- 45–72%：文案整体上移最多 18px，透明度降到 0.72。
- 55–88%：方块按深度分为三层，向上移动 8/14/22px，逐步变淡。
- 88–100%：只剩白色；不把方块变成河流、人物或点阵。

## 5. 四幕转场

### Hero → World in Motion

这是一个干净切换。方块完全消失后，章节编号与标题在白/纸色背景上进入；影片舞台随后用 1.05 → 1 的极轻缩放与透明度出现。总时长 1.1 秒，不做遮罩炫技。

### World in Motion → Living Memory

影片最后 600ms 逐渐曝光到白，结束后末帧保持 800ms。下一幕先留 300ms 纯白，再出现第一批蓝靛点。声音尾音可延长 1.2 秒，但不进入正文阅读区。

### Living Memory → Living Evidence

真人照片稳定后，点阵只保留 16–24 个点；它们在 900ms 内缩成 `signal-field` 抽象图左上区域的微小碎片。这个呼应只播放一次，随后点阵彻底退出。

### Living Evidence → Future

证据记录先停止所有状态变化，边框与状态标签在 700ms 内退为低对比；下方 Paper 色逐渐打开为白色地平线。不要把蓝方块放大成太阳，也不要把 UI 变形成未来场景。

## 6. 第二幕影片：28.8 秒 / 100 BPM

固定为 100 BPM、4/4、12 小节；每拍 0.6 秒，每小节 2.4 秒。无旁白、无字幕、无品牌口号叠字。

| 时间 | 画面 | 音画拍点 |
|---:|---|---|
| 0.0–2.4 | 冰川辫状水系航拍，匹配现有 poster | 水声先行，两颗木质/毡琴音进入 |
| 2.4–4.8 | 水道曲线切成真实显示器上的稀疏信号 | Click 落在第 1、3 拍；没有浮空 HUD |
| 4.8–7.2 | 研究者将 hydrophone 扣上湿缆并入海 | 金属扣与缆绳动作踩拍 |
| 7.2–9.6 | 水下设备下降，远处鲸影很小 | 抽走高频，只留低脉冲与水压感 |
| 9.6–12.0 | 船舱研究者扶住一侧耳机聆听 | 留半拍呼吸，两音动机回归 |
| 12.0–14.4 | 照护者将圆形传感器贴稳在普通人的衣物上 | 耳机圆形 match cut 到传感器 |
| 14.4–16.8 | 鲸声谱、生命信号、天文脉冲三个 0.8 秒近景 | 三颗短玻璃音触发切换，全片剪辑最密处 |
| 16.8–19.2 | 双手依次放下海洋、生命、天空三张透明信号膜 | 动作落第 1、2、4 拍，第 3 拍留空 |
| 19.2–21.6 | 缺失带出现，手停顿并重新比较 | 第 3 拍故意缺失，用“缺拍”表达冲突 |
| 21.6–24.0 | 横移信号膜；切到传感器或校准轮被调稳 | 一个克制确认音，不使用成功提示特效 |
| 24.0–26.4 | 两位研究者自然走过望远镜阵列 | 脚步落第 2、4 拍，不英雄化 |
| 26.4–28.8 | 宽阔海面或冰川入海，远处研究船与鲸呼吸 | 开放 add9 和弦，最后只剩水、风、呼吸 |

音乐使用 felt piano、木质敲击、短玻璃音、软刷奏、很轻的低频脉冲，并保留真实水、缆绳、布料、机械触点声。80% 使用硬切或形状/动作 match cut；轻快来自镜头关系，不来自快放、甩镜或史诗配乐。

### 网页播放规则

- 舞台达到约 35% 可见时从 0 秒自主播放；`scrollY` 永远不写入 `currentTime`。
- 默认 muted autoplay，静音观看也必须完整成立。
- 用户点击 `Watch with sound` 后从 0 秒重新播放完整音画版本。
- 低于 15% 可见时暂停；短暂返回续播，离开超过 8 秒再返回则从头开始。
- 播完保持末帧 1 秒，再用 4–8 帧水纹溶接回首帧；不硬跳。
- 影片上不盖标题、长文、CTA 或进度条；只允许右下角声音/重播控件。

## 7. 第三幕：点阵到人的尺度

首次达到 35% 可见时播放一次，总时长 5.1 秒；不循环，不要求用户停留。离开视口时暂停，回来续播。标题、正文与真人照片始终在正常文档流中。

| 状态 | 时段 | 画面 |
|---|---:|---|
| Idle | 0–300ms | 约 15% 环境点静止，先让文案被读到 |
| Forming | 300–1,800ms | 点按固定种子坐标汇聚成正在观察/记录的人物侧影或手部动作 |
| Dense | 1,800–2,700ms | 密度短暂提高 900ms，形成“共同记忆场” |
| Resolving | 2,700–4,200ms | 80% 点淡出，其余点收向真人照片的观察动作 |
| Human | 4,200–5,100ms | 真人照片由 0.82 → 1 opacity，点阵退为零 |
| Settled | 5,100ms 后 | 完全静态，不再次播放 |

桌面最多 360 点、平板 220 点、手机 120 点。只使用 transform 与 opacity；不逐点加滤镜、阴影或模糊。精细指针设备只在 Dense 状态扰动最近 12 个点，位移不超过 5px，30fps 上限。

## 8. Living Evidence：单槽三态

这里不是三张卡片，也不是流水线。左侧文案与右侧单一图像槽共同构成一个对象的三个状态。

### 自动演示（仅首次进入）

1. **Search / Stable — 2.2s**  
   `signal-field-v1` 显示混乱信号被找到并形成可用通路。
2. **Transition — 400ms**  
   140ms 淡至 0.15，换图后 260ms 淡入。
3. **Assimilation / Stable — 2.4s**  
   `living-memory-v1` 表达来源、变化、冲突与历史被保留下来。
4. **Self-healing / Broken — 350ms**  
   路径明确中断，最后验证状态仍保留。
5. **Candidate A / Testing — 550ms**  
   第一个有限候选被测试。
6. **Candidate A / Rejected — 300ms**  
   候选退回，低饱和铁锈色只用于小状态文字，不闪烁。
7. **Candidate B / Testing — 650ms**  
   第二个有限候选进入验证。
8. **Verified recovery — 500ms**  
   `resolved-fact-v2` 的蓝方块落定，连接恢复。
9. **Settled — 1.2s 后永久静止**  
   小句保留：`Unresolved failures remain explicit.`

这不是“必然成功”的承诺：只有通过验证的候选才恢复；没有候选通过时，必须退回最后验证状态并显示 `UNRESOLVED`。

### 用户接管

- 用户点击、键盘切换或触摸后，自动演示立即停止，不再抢回控制。
- 最后一次选择生效；旧 timer 必须全部取消。
- ArrowLeft/ArrowRight、Home/End 支持 Tab 导航。
- 自愈状态变化通过 `aria-live="polite"` 宣布。
- 手动切换采用 400ms 图像交接，不进行连续滚动 scrub。

### 证据记录进入

三态演示稳定后，证据记录由下方进入 24px、900ms；来源行按 80ms 间隔出现。状态、来源与冲突信息不依赖动画，动画失败时仍然完整可读。

## 9. 第四幕：未来

这是全站最低动态区。

- 标题进入 900ms；Lead 延后 140ms。
- 三句 `For…` 每句间隔 180ms，单句只上移 10px。
- 最终小句停顿 500ms 后出现；CTA 再延后 220ms。
- 地平线只做 1.02 → 1 的极慢尺度变化，持续 12 秒，最大透明度 0.32。
- 页面到达 CTA 后停止所有环境运动，让用户做决定。

## 10. Reduced motion

当 `prefers-reduced-motion: reduce` 启用：

- Hero 直接显示 Recognize 的静态排列帧，不循环、不视差。
- 所有文案与章节即时出现，最多保留 120ms opacity。
- 影片显示冰川 poster 和显式播放按钮，不自动播放。
- 点阵直接显示 Settled：真人照片与静态说明，不播放 Dense 和指针扰动。
- Living Evidence 不自动轮播；点击 Tab 即时换图。
- Self-healing 显示静态摘要：候选只有验证通过才恢复，否则回到最后验证状态并保持 unresolved。
- 关闭平滑滚动、sticky 视觉状态和所有长循环。

低性能模式在 `saveData`、`deviceMemory <= 4`、`hardwareConcurrency <= 4` 或视口 `<768px` 任一成立时启用：降低点数、关闭指针响应、不预载全部抽象图、影片使用 poster 优先。

## 11. 运行与性能边界

- 页面隐藏、区块低于 15% 可见时，停止计时器、Canvas 与视频。
- Hero 与点阵优先 Canvas 2D；GSAP 只编排状态，不逐点操作大量 DOM。
- 桌面 DPR 上限 1.75，移动端上限 1.25。
- `will-change` 只在动画运行时添加，结束后立即移除。
- 视频与全屏点阵不会同时运行高负载状态。
- 动画不改变布局高度，不产生 CLS。
- 桌面目标 55–60fps，低端手机至少 30fps，单个主线程任务小于 50ms。

## 12. 验收条件

- 快速滚到底仍能读完整叙事，没有内容依赖动画出现。
- Hero 循环看不出首尾跳帧；方块从不组成字符、线条或 Logo。
- 影片静音成立、有声重新从第 1 拍播放，音乐始终与剪辑同步。
- 点阵只播放一次，照片出现后点阵完全退出。
- 产品快速切换 20 次后，激活 Tab、图片、caption 与 ARIA 状态仍一致。
- 自愈至少显示一个被拒候选；无验证结果时不能留下 `RESOLVED`。
- Reduced Motion 下信息完整、无自动播放、无滚动吸附。

## 13. 确认后实施顺序

1. 建立 motion tokens、可见性控制器和 reduced-motion 状态。
2. 实现 Hero 方块矩阵与 16 秒循环。
3. 接入影片 poster、播放边界和声音按钮；正式视频资产到位后替换 source。
4. 实现点阵一次性状态机。
5. 实现 Living Evidence 自动演示、用户接管与显式失败分支。
6. 实现四幕转场、移动端回退与性能 QA。
