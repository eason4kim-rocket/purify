For developers

The receipt is in the response.

GET /search returns results the way your agent needs them — the snapshot ID, the observed time, and a signed receipt, inline.

  • snapshot_id pins the exact bytes an answer was read from
  • observed_at timestamps every read
  • The receipt replays through /verify

Built-in verification

Disagreement stays on the record.

When sources conflict, Purify does not guess. Each claim stays attached to its source; nothing is promoted until verification settles it.

  • Conflicts retained, never hidden
  • Every source carries its observed time
  • One receipt covers the whole path
